# College Feedback Classifier

AI-powered project to classify student feedback into:
- Academics
- Facilities
- Administration

## Tech Stack
- IBM watsonx.ai
- FLAN-T5 foundation model
- Python
- Pandas
- IBM Cloud Object Storage

## How it works
1. Load dataset from IBM COS
2. Use few-shot prompting
3. Classify feedback using FLAN-T5
4. Export predictions to CSV
